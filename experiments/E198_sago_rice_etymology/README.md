# E198: Sago-Rice Etymology — The "sego" ← "*sagu" Hypothesis

**Status:** SUCCESS
**Date:** 2026-04-15
**Idea:** I-133
**Layer:** L7 (proposed) — Pre-rice subsistence taphonomy

## Hypothesis

Javanese "sego" (cooked rice) derives from PMP *sagu (sago palm starch), not from PMP *Semay (cooked rice). If correct, this implies pre-rice Java was a sago-based civilization whose material culture (all organic) left zero durable archaeological trace — constituting a 7th Layer of Darkness.

## Method

1. Comparative phonological analysis: PMP *sagu > Javanese sego vs PMP *Semay > sego
2. Cross-linguistic semantic shift parallels (English "corn", "meat", etc.)
3. ABVD agricultural vocabulary extraction for key AN languages
4. Taphonomic implications quantification

## Key Results

| Test | Result |
|------|--------|
| *sagu > sego phonology | REGULAR (a>e raising before back vowel, u>o lowering) |
| *Semay > sego phonology | IRREGULAR (m>g has no regular sound change) |
| Sundanese confirmation | "sangu" (cooked rice) — even closer to *sagu |
| Tengger form | "sego" — identical to Javanese (conservative dialect confirms antiquity) |
| Eastern Indonesia | "sagu" = primary staple (original meaning preserved where no rice transition) |
| Semantic shift parallel | Cross-linguistically common (staple term transfers to new staple) |

## Taphonomic Impact

- Sago processing: wooden troughs, bamboo containers, woven strainers — ALL organic
- No pottery needed (bamboo), no grinding stones (pith beaten, not ground), no storage pits (processed fresh)
- Even WITHOUT volcanism, sago civilization = archaeologically ephemeral
- Person-years invisible: 200M-750M (sago period ~3500-2500 BP, population 0.2-1M)

## Caveat

This is a HYPOTHESIS. The standard PMP *Semay reconstruction is established (Blust & Trussel). The *sagu derivation needs formal publication. Strongest evidence: Sundanese "sangu" is harder to derive from *Semay than from *sagu.

## Conclusion

The *sagu > sego etymology is phonologically more regular, semantically parallel, and independently confirmed by Sundanese. If correct, it reveals that Java's pre-rice subsistence economy was doubly invisible: organic material culture (Layer 7) + volcanic burial (Layer 1). The archaeological gap is deeper than volcanism alone can explain.
