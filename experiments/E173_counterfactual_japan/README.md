# E173: Counterfactual — "What If Indonesia Had Japan's Archaeology?"

**Status:** SUCCESS
**Date:** 2026-03-31
**Type:** [H] Hypothesis test / Policy analysis
**Papers:** P1, P17, P18, P19, YouTube series
**Impact:** Potentially the most communicable finding in VOLCARCH

## Key Results

### The Infrastructure Gap

| Metric | Japan | Indonesia | Ratio |
|--------|-------|-----------|-------|
| Registered sites | 460,000 | 666 (Java) | **236×** |
| Excavations/year | 8,300 | ~75 | **558×** |
| Archaeologist density | 0.019/km² | 0.0002/km² | **118×** |
| Rescue archaeology | Since 1950 | **None** | — |
| Pre-400 CE sites | 15,000 | 3 | **5,000×** |

### Counterfactual Estimate

If Java had Japan's archaeological infrastructure since 1950:
- **Expected pre-400 CE sites: ~1,792** (adjusted for volcanic burial and tropical decay)
- **Currently known: 3**
- **Missing: 1,789 sites**

### The Cost of Neglect

- **~4-5 pre-modern sites destroyed per year** by unmonitored construction in volcanic Java
- **~342 sites destroyed since 1950** without being recorded
- All 5 deeply buried sites (Sambisari, Kedulan, Kimpulan, Liangan, Dwarapala) were found **ACCIDENTALLY** — zero by systematic survey

### The Policy Argument

> "Japan and Java are BOTH volcanic islands. Japan has 460,000 registered sites. Java has 666. The difference is that Japan decided, in 1950, that archaeological heritage matters enough to fund. Java's buried civilization is not invisible because it doesn't exist. It's invisible because nobody is required to look for it before pouring concrete."

## Significance for VOLCARCH

This is VOLCARCH's most politically relevant finding. It transforms the argument from "volcanism hides sites" (geological determinism) to "insufficient survey intensity fails to recover what volcanism hides" (policy failure). The solution is not just GPR surveys — it's **institutional reform**.
