## Kill criteria (abandon research line if triggered)

### #1 Cascade falsification — **PARTIALLY VIOLATED IN SPIRIT**

**Criterion text:** *"E110 5-factor model is off by >2 orders of magnitude from observed gap, AND no reasonable parameter adjustment restores agreement."*

**Current state after E176 (ME#13):**
- Cascade NOT off by 2 orders — it DOES match observation (0.058% predicted vs 0.031% observed, within factor of 2).
- **BUT** 83.8% of random 5-factor draws also bracket observation (E176). The cascade is *over-parameterized*: its "match" is not evidence for the specific mechanism, only evidence that multi-factor decomposition is flexible enough to match.
- Cascade has been downgraded from "model matches data" (original framing) to "plausible mechanistic decomposition" (manifesto v4.1 update).

**Verdict:** The literal criterion is NOT triggered. But the criterion's underlying purpose — validating the cascade's explanatory power — is defeated by E176 over-parameterization. **The criterion is incoherent with current state** and should be replaced.

**Proposed replacement:** *"If the cascade model cannot produce a testable distinction between alternative decompositions (e.g., 3-factor vs 5-factor, with independent per-factor calibration), the theoretical contribution of the cascade should be explicitly withdrawn. Retained only as pedagogical illustration of compound taphonomy, not as validation of the multi-factor framework."*

### #2 Within-island control fails — **HOLDS**

**Criterion text:** *"pre-400 CE sites ARE present in volcanic East Java at comparable density to non-volcanic West Java."*

**Current state:** Volcanic East Java = 0 pre-400 CE open-air sites. Non-volcanic West Java = Buni Complex (400 BCE-500 CE) + Batujaya (1st-3rd c. CE burials) + Tarumanagara inscriptions (4-5th c.). **Differential is robust.**

**Verdict:** NOT TRIGGERED. Control holds. Session 19 counter-SLR actually strengthened this via Batujaya documentation.

### #3 External comparandum falsification — **YELLOW**

**Criterion text:** *"A volcanic tropical island shows rich pre-400 CE archaeology despite comparable sedimentation rates."*

**Current state (E201):** Philippine volcanic zones have ~25-40 pre-400 CE sites (vs 0 in volcanic Java). Literally: volcanic tropical islands DO show pre-400 CE archaeology.

**BUT:** Whether sedimentation rates are "comparable" is unverified. E178 identifies karst availability (Philippines abundant, Java minimal) as confounding factor. Volcanic density also differs (Philippines 0.07 per 1,000 km² vs Java 0.35).

**Verdict:** **AMBIGUOUS.** Criterion is either triggered (rich Philippines volcanic pre-400 CE record) or not (sedimentation/karst confounded). The criterion was written without operationalising "comparable sedimentation rates."

**Proposed refinement:** *"External comparandum falsification requires (a) total tephra deposition rate within 2× of Java (measured, not inferred), (b) karst-poor terrain comparable to volcanic Java interior, (c) documented pre-400 CE open-air sites. All three conditions must be met."*

Current state: No comparandum satisfies all three. Criterion is not triggered under the refined version. But this should be **acknowledged as a limitation in P0 §8**.
