## 1. Research Question

Can a supervised ML classifier trained on multi-season Sentinel-2 spectral features distinguish locations containing archaeological structures (known or buried) from non-archaeological controls in volcanic tropical Java at a level sufficient to propose top-K candidate locations for field verification in the volcanic interior?

No published application of this method exists for volcanic tropical Indonesia. Precedents: Parcak 2016 (Egypt), Evans 2013 (Angkor LiDAR), de Souza 2024 (Amazon).

---

## 2. Data and Method

### Training set

N = 190 sites with complete dry+wet season features:
- **6 hard positives** (class=2, double-weighted): discovered-buried candi (Sambisari 6.5m depth under Merapi ash; Kedulan 7m; Kimpulan 4-5m; Liangan wooden material preserved under Sindoro ash; Badut 5th c. CE Malang; Tigomangi 1358 CE East Java)
- **106 soft positives** (class=1): known monumental candi from OSM (east_java_sites.geojson, 15,011 features filtered) + Wikidata (391 records filtered) deduplicated at 200m tolerance
- **5 hard negatives** (class=-2): original E189 controls (plain/slope × 4 directions)
- **73 random negatives** (class=-1): stratified-random sampled, ≥5km from any positive, within Java bounds

### Sentinel-2 feature extraction

Via Microsoft Planetary Computer STAC API. Scene selection: cloud < 25%, sort by cloud ascending, with tile-diversity constraint (≥5 distinct MGRS tiles) to ensure Central + East Java coverage.

Per-site tile: 1000m × 1000m (100×100 pixels at 10m). Bands read: B03, B04, B08, B11, B12, SCL.

Per-site features (17 base × 3 seasonal = 51 features):
- NDVI mean/std/center/ring/diff/local-variance
- NDWI mean/std/center/ring/diff/local-variance
- MSAVI mean/center/diff
- Clay ratio (B11/B12), Iron oxide (B04/B03)
- All × {dry, wet, wet-dry delta}

Tile coverage: 195 sites successfully extracted dry, 230 wet; 190 sites had both seasons for complete feature vector.

### Classifiers

Trained on 190 sites × 51 features:
- **Random Forest**: 300 trees, max_depth=10, class_weight="balanced", hard-positive sample_weight=2.0
- **Gradient Boosting (sklearn)**: 200 trees, max_depth=5, learning_rate=0.05
- **Cross-validation**: 5-fold stratified + leave-one-hard-positive-out

## 3. Results

### Random Forest K-fold CV

| Fold | AUC | Accuracy |
|:---:|:---:|:---:|
| 1 | 0.872 | 0.842 |
| 2 | 0.945 | 0.895 |
| 3 | 0.815 | 0.789 |
| 4 | 0.821 | 0.763 |
| 5 | 0.767 | 0.737 |
| **Mean** | **0.844 ± 0.060** | **0.805** |

All folds exceed 0.75 threshold stated in README (H1). Variance tight despite small dataset.

### Leave-one-hard-positive-out

Each of 6 discovered-buried candi withheld in turn; classifier trained on remaining 189 sites; probability assigned to held-out site:

| Candi | p(buried) when held-out |
|---|:---:|
| Sambisari (6.5m deep) | 0.965 |
| Kedulan (7m deep) | 0.930 |
| Kimpulan (4-5m deep) | 0.883 |
| Liangan (wooden preserved) | 0.859 |
| Badut (5th c. CE) | 0.965 |
| Tigomangi (1358 CE relief) | 0.588 |
| **Mean** | **0.865** |

Five of six score > 0.85 when held out. Tigomangi lower (coordinates approximate, may not reflect precise burial context).

### Gradient Boosting K-fold

Mean AUC = 0.833 ± 0.048 — consistent with RF, confirms signal is not RF-specific overfitting.

### Top 10 features by RF importance

1. ndwi_mean_dry (0.070)
2. ndwi_ring_dry (0.051)
3. ndvi_ring_dry (0.048)
4. ndvi_mean_dry (0.043)
5. ndvi_center_dry (0.042)
6. msavi_mean_dry (0.040)
7. ndwi_center_dry (0.038)
8. clay_ratio_wet (0.033)
9. msavi_center_dry (0.032)
10. ndwi_std_dry (0.030)

Dry-season water and vegetation indices dominate, consistent with E189 Phase A finding that dry-season NDWI center-ring contrast was the strongest weak-signal indicator. The multi-feature RF leverages a diffuse signal across ~20 inter-correlated spectral features.

### Landscape prediction pipeline

Implemented as 04_predict_landscape.py: downloads per-basin composite via STAC, computes full-raster indices, slides 1000m × 1000m window with 500m stride, extracts training-compatible feature vectors per window, applies RF classifier, exports probability raster + top-20 GeoJSON.

First run on Malang basin returned usable probabilities (0.040–0.953 range across 98 grid points) but composite coverage was incomplete: single Sentinel-2 scene intersected the 44×44 km basin bbox as a 50×1.15 km strip. Top-20 candidate latitudes clustered at -7.755° across a longitude range 112.46–112.58. **Pipeline validated; multi-scene mosaic fix queued as next task.**

## 4. Interpretation

- **Signal is real.** AUC 0.844 with tight K-fold variance plus leave-one-hard-positive-out 0.865 on independently-discovered buried candi is not explained by class imbalance or feature-count inflation. Dry-season spectral contrast IS informative about archaeological presence in volcanic tropical Java.
- **Signal comes from subtle multi-feature pattern, not any single band.** E189 Phase A identified weak NDWI center-ring difference (p=0.032); E209 shows that combining ~50 features lifts AUC to 0.844, which is archaeologically useful.
- **Signal generalises to discovered-buried sites.** Sambisari (6.5m buried) scores 0.965 when held out. The classifier is not merely learning surface-candi decorative patterns.
- **Tigomangi at 0.588 is a reminder.** Coordinates were approximate; signal degrades quickly with position uncertainty. Field deployment will require sub-100m coordinate precision to meet training-set assumptions.

---

## 5. Limitations acknowledged

1. **Training set small (N=190).** 5-fold CV with 38 sites per fold carries real variance. Results should be treated as preliminary until N ≥ 300.
2. **Only Sentinel-2 features used.** SAR and DEM features planned for Phase 2 (E209 README §3). The ME#16 diamond-hunt plan was to stack multiple signals; current results use only optical.
3. **Landscape prediction pipeline incomplete.** Composite coverage bug blocks full basin-scale output. Top-20 coordinates from the current Malang run are a cohesive strip, not a landscape sample.
4. **Random-negative extraction had 45% failure rate in wet season.** STAC scene coverage gaps meant 90/200 RN sites couldn't be processed. Training set is biased toward sites in well-covered tiles.
5. **Single-investigator + AI validation only.** No external peer review of classifier methodology yet; cross-model hostile review is the partial mitigation.
