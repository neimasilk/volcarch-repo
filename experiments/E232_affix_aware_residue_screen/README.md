# E232: Affix-aware residue screen — Tolaki pilot (idea I-150)

**Status:** PRE-REGISTERED (DESIGN.md, 2026-10-15) — not run; runs only after the PI has read the design (orbit agenda K7)
**Line:** 04_language_text · **Paper:** P8 follow-up (not part of P8 R1) · **Idea:** I-150

**Hypothesis:** stripping the affixes listed in a published Tolaki grammar finds more same-meaning look-alikes between
uncoded Tolaki forms and ABVD's PMP forms than P8's blind rule (ignore up to three leading letters), beyond what stripping
arbitrary strings of the same size finds, without losing sensitivity on forms ABVD codes in the PMP set.

**Method:** see `DESIGN.md` — affix inventory from Mead (1998) with page references, frozen before any run; arms A
(P8 rule), B (grammar stripping), C (union); chance from 50 random other meanings; positive control = the 50 Tolaki forms
ABVD places in the PMP entry's set; null = 200 random inventories of the same size.

**Data:** ABVD CLDF snapshot 917c5a5 (Tolaki 674, PMP 269), as E231 §D. Baseline: 12 of 128 look-alikes, chance 1.9 %,
sensitivity 24 of 50.

**Result:** none yet. **Conclusion:** none yet.

**Decision rule:** GAIN / NO GAIN / INFLATION / PARTIAL, fixed in `DESIGN.md` §6. "No gain" is a valid result.
