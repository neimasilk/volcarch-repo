makna tak-berkode (34,8 % vs 23,4 / 19,0), penyebab tidak diputuskan; Tolaki 70,9 % punya padanan rupa di Bungku-Tolaki (10,5 %
kebetulan); uji permutasi: kelebihan kecil, tanpa klaim lapisan bersama; "coding status is not origin". **Jangan pernah ditulis**
(rencana kerja §10.7): "Makasar reproduced/consistent", "only not yet coded", "more prefixes", "no large shared layer", κ 0,61, 266
bentuk konsensus, 0,763 "phonological only", F1 0,82 sebagai skor deteksi.
