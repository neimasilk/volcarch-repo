# Proposal Workshop: Metode Komputasional untuk Survei Arkeologi

**Target:** Balai Arkeologi Yogyakarta / BPCB Jawa Timur
**Durasi:** 2 hari (16 jam)
**Peserta:** 15-20 arkeolog + staf BPCB
**Biaya:** Rp 10-15 juta (sewa ruang + konsumsi + honorarium)
**Tridarma:** Pengabdian kepada masyarakat

---

## Latar Belakang

Survei arkeologi di Indonesia masih bergantung pada metode permukaan konvensional yang hanya mampu mendeteksi objek di kedalaman <50 cm. Proyek VOLCARCH menunjukkan bahwa situs pra-Hindu di Jawa vulkanik terkubur 5-10 meter di bawah permukaan — tidak terdeteksi oleh metode standar.

Workshop ini memperkenalkan metode komputasional yang dapat membantu arkeolog Indonesia memprediksi lokasi situs terkubur SEBELUM melakukan penggalian.

## Tujuan

1. Peserta memahami konsep bias tafonomi vulkanik dan implikasinya
2. Peserta mampu menggunakan GIS (QGIS) untuk analisis spasial situs
3. Peserta memahami dasar-dasar interpretasi data GPR/ERT
4. Peserta mendapat akses ke dataset dan tools VOLCARCH (open source)
