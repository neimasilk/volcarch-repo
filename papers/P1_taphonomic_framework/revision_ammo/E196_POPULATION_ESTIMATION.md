## The Problem

Reviewer: "Maybe Java just wasn't populated before 400 CE."

## The Answer

Four independent estimation methods (growth back-projection, carrying capacity, comparative island scaling, Sunda Shelf displacement) converge on **~1-2 million people on Java at 400 CE** (minimum: 631,000). At Philippine archaeological site-density rates, this population should have produced **at least 694 known sites**. We observe **zero** in volcanic Java's interior.

## Key Sentence

> "Monte Carlo population estimation using four independent methods — demographic back-projection from published 1600 CE anchors (Reid 1988), ecological carrying capacity, comparative Austronesian island scaling, and Sunda Shelf displacement modelling — converges on 1–2 million inhabitants of Java by 400 CE (minimum plausible: 631,000; 100,000 draws per method). At archaeological site-density rates observed in the Philippines — a comparable Austronesian context with non-volcanic preservation — this population should have generated at least 694 detectable sites. Zero pre-400 CE open-air sites are known from Java's volcanic interior, implying a taphonomic suppression factor of ≥694×."

## Key Numbers

- Minimum plausible population: 631,059
- Central estimate: ~1.5 million (geometric mean of two best methods)
- Expected sites: 694+ (minimum) to 4,272 (central)
- Observed sites: 0
- **Suppression factor: ≥694×**
- Invisible person-centuries: ~46.6 million

## The Philippines Comparison

This is the most devastating argument:
- Philippines 1600 CE density: 5.7/km²
- Java 400 CE minimum density: 4.9/km²
- Same Austronesian culture, same density range
- Philippines: 4,000+ pre-colonial sites
- Volcanic Java: 0 pre-400 CE open-air sites
- **Same people. Same density. Different geology. Different archaeological record.**
