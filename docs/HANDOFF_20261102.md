  the next one. A file shows in the grid as soon as step 3 is reached; "Complete" closes the wizard. **The revision flow has no
  Comments-to-the-Editor field** → use Review Discussions → Add discussion (tick the editor; TinyMCE body set through
  `tinymce` in `browser_evaluate`).

  `…/api/file/file-api/download-file?submissionFileId=N&submissionId=280&stageId=3`, base64, `filename` **inside
  `.playwright-mcp/`** (the MCP refuses scratchpad paths); decode and compare with PyMuPDF.
- `build_jcaa_bibliography.py` needs the .tex as argument: `python build_jcaa_bibliography.py submission_jcaa_v0.3.tex`.
- `build_supplement.py v0.3` (defaults to v0.2). Figures 1/5: `build_v03_figures.py` functions `fig_study_area()` and
