## Why Philippines is the Critical Comparandum

VOLCARCH currently uses two comparanda:
1. **Kalimantan** (zero volcanism, earliest kingdom Kutai ~400 CE → visible because unburied)
2. **Japan** (high volcanism, rich record → visible because massive survey investment, E086)

Both are informative but imperfect. Philippines is BETTER because:
- **Same Austronesian cultural sphere** as Java (shared deep ancestry, language family, material culture)
- **Lower volcanic density** than Java (22 active volcanoes in 300,000 km² vs Java's 45 in 129,000 km²)
- **More karst/limestone** (better cave preservation)
- **Similar colonial archaeology history** (Spanish vs Dutch, similar institutional gaps)
- **Similar tropical climate** (organic decay rates comparable)

The Philippines can DISTINGUISH between two explanations:
- If Philippines has rich pre-400 CE record → problem is VOLCANIC BURIAL (Java-specific)
- If Philippines also sparse → problem is ORGANIC CIVILIZATION + TROPICAL DECAY (pan-Austronesian)

## Philippines Pre-400 CE Archaeological Record

### Major Pre-400 CE Sites

| Site | Location | Date | Significance |
|------|----------|------|--------------|
| **Callao Cave** | Cagayan, Luzon | ~67,000 BP | *Homo luzonensis* — entirely new hominin species |
| **Tabon Cave** | Palawan | ~47,000-22,000 BP | Earliest *H. sapiens* in Philippines |
| **Ille Cave** | Palawan | ~14,000 BP–present | Continuous occupation, burials, rich organic |
| **Manunggul Cave** | Palawan | ~890-710 BCE | Famous burial jar with "ship of the dead" lid |
| **Arku Cave** | Cagayan, Luzon | ~5,000 BP | Neolithic |
| **Dimolit** | Isabela, Luzon | ~3,500 BP | Neolithic pottery |
| **Nagsabaran** | Cagayan, Luzon | ~4,000-2,000 BP | Rice agriculture evidence |
| **Kalanay Cave** | Masbate | ~400 BCE-200 CE | Iron Age pottery |
| **Butuan** | Mindanao | ~10th c. CE but earlier layers | Balangay boats (pre-Hindu maritime) |
| Sa Huynh-related | Multiple | ~500 BCE-200 CE | Trade network evidence (earrings, beads) |

### Key Observations

1. **Philippines has a RICHER pre-400 CE record than Java.** Multiple cave sites with continuous occupation spanning tens of thousands of years. Java has almost nothing before ~400 CE in volcanic zones.

2. **BUT most Philippines pre-400 CE sites are CAVE SITES in limestone/karst.** Tabon, Ille, Callao, Manunggul — all cave contexts. Open-air pre-400 CE sites are rare in Philippines too.

3. **Philippines has Sa Huynh-related trade network evidence** (glass and carnelian beads, double-headed earrings) dating to 500 BCE-200 CE — parallel to Java's Buni Complex. Both are COASTAL trade evidence.

4. **Philippines' open-air pre-400 CE sites are also sparse.** The rich record is almost entirely in caves.

## Survey Intensity Comparison

| Metric | Philippines | Indonesia | Ratio |
|--------|------------|-----------|-------|
| Registered sites | ~5,000-8,000 (estimated) | ~20,000+ | ~0.3× |
| Annual excavations | ~30-50 (estimated) | ~70 (estimated) | ~0.5× |
| Mandatory rescue archaeology | **NO** (Republic Act 10066 protects sites but no mandatory excavation) | **NO** | Same |
| Primary survey body | National Museum of the Philippines | BRIN + BPCB (regional) | Similar |
| Colonial survey intensity | Low (Spanish focused on churches, forts) | Higher (Dutch OV surveys from 1901) | PH < ID |

**Critical finding:** Philippines has LOWER survey intensity than Indonesia, yet has a RICHER pre-400 CE record. This is significant for VOLCARCH.

## Analysis for VOLCARCH

### What the Philippines comparison shows:

1. **Volcanic burial is NOT the only explanation, but it is A significant factor.**
   - Philippines (less volcanic) has richer pre-400 CE record despite LESS survey effort
   - This SUPPORTS the volcanic burial thesis as a partial explanation
   - But it also shows that KARST AVAILABILITY matters enormously — Philippines' record is almost entirely cave-based

2. **The organic civilization problem is PAN-AUSTRONESIAN.**
   - Even in Philippines, open-air pre-400 CE sites are rare
   - Organic architecture + tropical climate = universal preservation problem
   - This SUPPORTS the "bamboo civilization" thesis (E040) beyond Java

3. **The survey deficit is NOT the whole story.**
   - If survey deficit were the primary explanation, Philippines (less survey) should have FEWER pre-400 CE sites. It has MORE.
   - The difference is CAVE AVAILABILITY. Philippines has extensive karst; volcanic Java has very little.
   - Caves act as natural preservation capsules (stable temperature, dry, sealed from tropical weathering)

4. **New framing: VOLCARCH should add "cave availability" as a factor.**
   - Current cascade model (E110) has 5 factors. Cave availability could be factor 6: the presence/absence of natural preservation environments.
   - Java's volcanic zones have very few caves (volcanic rock ≠ karst). Philippines' limestone has many.
   - This strengthens the overall argument: Java lacks BOTH caves AND unburied surfaces.

### Quantitative comparison (rough)

| Parameter | Philippines | Volcanic Java | Non-volcanic Java |
|-----------|------------|---------------|-------------------|
| Pre-400 CE sites | ~15-25 known | 0-3 | 5-10 (Buni, Batujaya) |
| Cave sites available | Hundreds | Very few | Moderate (south coast karst) |
| Volcanic sedimentation | Low-moderate | 2.4-6.2 mm/yr | ~0 |
| Survey intensity | Low | Low-moderate | Low |

## Potential Experiment

**E115 (or next): Philippines-Java Archaeological Record Comparison**

**Hypothesis:** The density of pre-400 CE archaeological sites correlates inversely with volcanic density and positively with karst/limestone availability, after controlling for survey intensity.

**Method:**
1. Compile pre-400 CE site counts for: Philippines, Java volcanic, Java non-volcanic, Kalimantan, Sulawesi
2. Compute volcanic density (active vents per 1000 km²), karst area fraction, and survey intensity proxy for each region
3. Multiple regression: sites ~ volcanic_density + karst_fraction + survey_intensity
4. Test which factor has the largest effect size

**Data needed:**
- Philippines site catalog (National Museum database, or compiled from Bellwood 2017, Mijares 2010)
- Karst area estimates per region (geological survey data)
- Survey intensity proxies (excavation counts per year per region)
