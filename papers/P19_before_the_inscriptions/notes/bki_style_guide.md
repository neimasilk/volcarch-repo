# BKI Style Guide for P19

**Source:** BKI Author Instructions (Brill, last revised 11 Nov 2013) + analysis of Griffiths, Sastrawan & Bastiawan (2024) "Restoring a Javanese Inscription" (BKI 180:133-211) + Bloembergen & Eickhoff (2011) "Conserving the past" (BKI 167:405-436).

## Formal Requirements

| Spec | Requirement |
|------|-------------|
| **Word limit** | 12,000 words INCLUDING notes + bibliography (~25 printed pages) |
| **Language** | British English (honour, realise but organize, -ize endings) |
| **Abstract** | ~200 words |
| **Keywords** | 2-6 keywords |
| **Citation style** | Author-date in text: `(De Jonge 1980:234-5)` — no space before colon |
| **Notes** | Footnotes (substantive discussion, not just references) |
| **Bibliography** | Alphabetical, all cited works only. Full titles with subtitles separated by semicolon |
| **Headings** | Numbered: `1`, `1.1`, `1.1.2` — no "§" symbol |
| **Spacing** | Double-spaced throughout |
| **Paragraphs** | No indentation at start of new paragraph |
| **Abbreviations** | AVOID: e.g., etc., cf., op cit., i.e. Write out in full |
| **Diacritics font** | Palatino |
| **Indonesian names** | Personal names in original spellings; geographical names in modern spellings |
| **Submission** | Editorial Manager: editorialmanager.com/bki |
| **License** | CC BY-NC 3.0 (copyright stays with author) |
| **APC** | Waived by KITLV — Diamond OA |
| **Peer review** | Double anonymous, ~20 weeks |

## What BKI Wants (from KITLV page)

> "Articles aim to reach out to a broader audience than the one defined by a specific discipline, and highlight the socio-political relevance of the object of study."

> "Articles requiring significant technical knowledge from our readers (e.g., some economic or linguistic studies) are considered more suited for a disciplinary journal and will NOT be accepted."

**Translation for P19:** No Monte Carlo simulations, no AUC scores, no regression tables. VOLCARCH evidence must be presented narratively, not technically.

```

```

**Journal article:**
```

```

**Chapter in edited book:**
```

1982 'Health programmes directed to urban squatter populations', in: J.L. Taylor
    and D.G. Williams (eds.), Urban planning practice in developing countries,
    pp. 301-20. New York: Pergamon Press.
```

**Note:** Single quotes around article/chapter titles. Italics for book/journal titles. Indonesian composite names listed by first name (Sartono Kartodirdjo under S). Dutch prefixed names under main name, not prefix (Van Mook under M, De Jonge under J).

## Writing Style Observations (from Griffiths et al. 2024)

### 1. Opening Strategy: Narrative Hook
The Griffiths article opens NOT with theory or literature review but with a vivid historical scene:

> "On 2 August 928, the village of Sangguran in East Java was demarcated as a sīma (benefice) of a nearby Śaiva temple, by decree of the reigning king, King Wawa."

**Lesson for P19:** Open with Lombard's metaphor as narrative, not as academic citation.

### 2. Tone: Scholarly but Accessible
- Uses narrative to carry technical content
- Colonial provenance traced as detective story
- Heritage/repatriation framing adds contemporary relevance
- Footnotes carry detailed scholarly discussion (who said what, why it matters)
- Measured, never polemical — even when making strong claims

### 3. Section Structure (Griffiths example)
```
1 Introduction
2 Provenance
3 History of Research
4 Heritage Status
5 The Inscription (philological core)
6 Historical Discussion
7 Conclusion
```

### 4. Footnotes: Substantial
BKI footnotes are NOT just page references. They contain:
- Scholarly disagreements ("Blasius Suprapta (2015:172,246) proposes a set of identifications that differs in large part from ours")
- Contextual explanations
- Methodological asides
- Cross-references to other primary sources

### 5. Keyword Style
Keywords are separated by en dashes, lowercase:
```
epigraphy – history – provenance research – heritage – language – Java – King Wawa – King Sindok
```

## What This Means for P19

### DO:
- Write narratively — tell stories (Sambisari discovery, Candi Kedulan)
- Frame through socio-political relevance (heritage policy, national identity, decolonization)
- Engage deeply with humanities literature (Lombard, Wolters, Bloembergen, Sears, Chakrabarty)
- Use footnotes for scholarly apparatus and nuance
- Present VOLCARCH evidence as illustrative, not conclusive
- Use British English throughout
- Keep under 12,000 words including notes + bibliography

### DON'T:
- Include any technical statistics (no p-values, no AUC, no Monte Carlo)
- Use experiment labels (no "E058", "E110")
- Present computational analysis as primary evidence
- Write in a technical/scientific register
- Use section symbols (§) — use numbered headings
- Abbreviate (write "for example" not "e.g.")
