# E079: The Archaeological Darkness Index — Grand Synthesis

## Hypothesis
The gap between expected and observed evidence for Java can be quantified century-by-century, producing a "Darkness Index" that measures archaeological invisibility.

## Method
Integrates 6 evidence dimensions across 45 centuries (3000 BCE-1500 CE):
1. Inscription density (E074, E078)
2. External recognition (E071, Chinese/Indian/Greek/Roman sources)
3. Known archaeological sites (E001, E071)
4. Volcanic sedimentation rate (E075)
5. Material preservation probability (E074 organic/mineral ratio)
6. Population trajectory (demographic estimates)

Darkness Index = f(expected - observed) × burial × decay

## Key Results

### The Invisible Millennium (1-400 CE)
| Metric | 1-400 CE | 700-1000 CE (Classical) |
|--------|----------|-------------------------|
| Darkness Index | **0.515** | **0.273** |
| External sources | 8 | 9 |
| Known sites | 10 | 70 |
| Inscriptions | 0 | 64 |

**The Invisible Millennium is 1.9× darker** despite comparable external recognition.

### Brightest and Darkest Centuries
- Brightest: C10 (901-1000 CE, DI=0.193) — peak East Java inscriptions
- Darkest (post-Neolithic): C1 (1-100 CE, DI=0.528) — external sources confirm trade but zero local records

### Evidence Convergence
6 independent factors all predict darkness:
1. Volcanic burial: 1.2-2.0m deposit over 400 years (E075)
2. Organic decay: 5% material survival vs 25-30% for classical (E074)
3. No writing: Sanskrit adopted ~400 CE (E071)
4. Eruption disruption: 6.3× fewer inscriptions in eruption decades (E078)
5. Spatial encoding: knowledge was behavioral, not textual (E073)
6. Administrative pre-existence: governing vocabulary predates Indianization (E074)
