# E145: Eruption Frequency vs Archaeological Visibility
**Date:** 2026-03-30 | **Status:** INFO NEG | **Paper:** P1

Eruptions POSITIVELY correlate with inscriptions (rho=0.908, p=0.0001).
Counter-intuitive but explained by temporal confound: powerful kingdoms
produce both inscriptions AND documented eruptions. Taphonomic effect
is SPATIAL (depth vs distance), not temporal (eruptions per century).
Confirms E120: cascade model > simple eruption count.
