# E214 — Palynological / Charcoal Test of Pre-400 CE Human Impact in Java

**Status:** SUCCESS (as a test) — result LEANS AGAINST the strong thesis. **First independent material counter-evidence in the project.**
**Date:** 2026-06-08
**Method:** AI research-agent systematic literature search (~20 searches, ~15 fetch attempts). **Integrity caveat:** publisher full-texts were largely blocked (HTTP 403); most extractions are from search-result snippets quoting abstracts, cross-corroborated ≥2 queries per record. DOIs/citations are real; unconfirmed numerics flagged. Directional conclusion is consistent with the established literature (esp. the 2011 *Quaternary International* Java review), so trusted; specific dates carry snippet-level uncertainty.

## Hypothesis (falsification test, per ME#17 §8)
If a substantial farming population existed in Java before ~400 CE, the pollen + sedimentary-charcoal record should show forest clearance / burning / cultigens BEFORE ~1550 cal BP — **independent of whether archaeological sites are buried.** Pollen does not care about tephra burial. So this channel can CONFIRM or REFUTE the hidden-population thesis on its own.

## Result — LEANS AGAINST a LARGE pre-400 CE population
**Every directly-dated Java terrestrial record places clear anthropogenic clearance LATE:**

| Site (Java) | Clearance onset | Class | Source |
|---|---|---|---|
| Dieng / Telaga Balekambang (C Java highland) | **~1350 BP (~600 CE)**, tied to Hindu-Javanese center | post-400 CE | Pudjoarinto & Cushing 2001, RPP 116:13–45 |
| Rawa Danau (W Java swamp) | **~AD 1770**; open last ~200–400 yr | post-400 CE | Yulianto et al. 2005, Tropics 14:271 |
| Teluk Banten (N coast W Java) | "historic times" | post-400 CE | van der Kaars & van den Bergh 2004, JQS 19:229 |
| Bandung Basin (W Java) | late Holocene; LGM grass = climatic | climate→late | van der Kaars & Dam 1995, P3 117:55 |
| Situ Bayongbong (W Java highland) | no early human signal; climate-driven | ambiguous | Stuijts 1993, MQRSEA 12 |
| **Marine core off Solo R. (N Java)** | **~2950 cal BP (~1000 BCE)** canopy decline, "possibly human" (hedged, huge catchment, climate confound) | **pre-400 CE loophole** | Poliakova/Zonneveld et al. 2017, RPP 244 |
| Java synthesis review | "impact… not until late Holocene, after the rise of the ancient kingdoms, **c. 1500 yr ago**" | post-400 CE | "Rain forest in Java through the Quaternary" 2011, Quat. Int. |

**Critical contrast (the method works):** Sumatra (Maloney 1980, Toba ~7,500 BP), Borneo (Niah ~6,000 cal BP; Sentarum ~3,000 BP) **DO** show robust mid-Holocene farming/clearance. So Java's lateness is a real signal — OR severe undersampling.

## Honest verdict (calibrated, not motivated)
The palynological channel **does NOT support, and partially REFUTES, a LARGE landscape-clearing pre-400 CE Javanese population.** It is consistent with EITHER (a) genuinely no substantial population, OR (b) a small / dispersed / non-forest-clearing population (swidden / arboriculture / forest-garden) below regional pollen detection. It currently **cannot distinguish (a) from (b)** because of two legitimate escapes:
1. **Undersampling:** Java has essentially NO high-resolution lowland-agricultural core spanning 0–500 CE at the inscription heartlands (Kedu/Brantas). Existing cores are highland, climate-dominated, or marine-integrated.
2. **The Solo marine loophole** (~2950 cal BP), ambiguous.

**This kills the project's "0 counter-evidence" claim.** We now have material counter-evidence and it must be foregrounded (integrity).

## Productive reframe (must itself stay falsifiable — do NOT spin into a new unfalsifiable story)
The result is consistent with a **dispersed, forest-integrated, arboriculture/swidden society** with rich native vocabulary (cf. linguistic-substrate experiments) but no landscape-scale forest clearance, no monuments, no inscriptions — invisible to archaeology AND palaeoecology simultaneously. The "darkness" may not be a buried metropolis but a low-visibility *mode of life*. This is weaker, more honest, and more interesting than the strong thesis — BUT it needs its own tests:
