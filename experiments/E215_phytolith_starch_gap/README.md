# E215 — Phytolith / Starch-Grain Test of Pre-400 CE Cultivation in Java

**Status:** SUCCESS (as a test). Result = **DATA VOID, not empty** — the decisive test has never been run in Java.
**Date:** 2026-06-08 · Companion to [E214 palynology]. Method: AI research-agent SLR (caveat: many publisher full-texts paywalled; records cross-corroborated, DOIs real).

## Hypothesis (per ME#17 §8 / peradaban-vulkanik reframe)
Pollen (E214) detects only LANDSCAPE-scale clearance, so it misses a small/dispersed population. **Phytoliths & starch grains detect plant USE directly** (sediment, stone-tool/pottery residue, dental calculus) even for non-forest-clearing crops (taro, banana, yam, sago, arboriculture). So this channel can detect exactly the kind of dispersed cultivation the peradaban-vulkanik reframe predicts — the one pollen would miss.

## Result — VOID, leaning "unstudied" not "empty"
**Zero verified phytolith/starch records of crop use from Java before ~400 CE — because no microbotanical residue study has EVER been published for any prehistoric Java site** (not sediment, stone-tool, pottery, or dental calculus). The method demonstrably works at the same latitudes:

| Site | Region | Method | Date | Finding | Class |
|---|---|---|---|---|---|
| Minanga Sipakko/Kamassi | **Sulawesi** | phytoliths (sediment) | ~3,500 BP (AMS) | domesticated *Oryza* — oldest secure rice in Indonesia | comparator |
| Niah Cave | **Borneo** | starch + parenchyma | Pleistocene | wild aroids/yam/sago — *foraging* baseline | comparator |
| Kuk Swamp | **New Guinea** | phytolith+starch+pollen | taro early Holocene; banana ~6,500 BP | independent agric. origin | comparator |
| Liyangan/Liangan | **C Java** (Sindoro) | carbonised rice **macro-remains** (NOT microbotanical) | **~9th c AD** | tropical japonica rice | (b) post-400 CE |
| Gunung Sewu caves (Song Terus, Braholo, Song Keplek, Gua Mandung) | **Java** | lithics/bone/fauna only — **no microbotanical study** | L.Pleist.–Holocene | plants never analysed | (c) UNSTUDIED |

**Verdict:** the channel **leaves the pre-400 CE question OPEN** and reveals the decisive test has not been run. Java's richest Holocene cave sequences have plant-processing tools (pounders/pestles) but no starch/phytolith residue analysis. So Java is a genuine **data void**, not demonstrated emptiness. High-value, low-competition target.

## The decisive falsification test (concrete, low-cost, high-impact)
Run microbotanical (phytolith/starch) analysis on Java material:
1. **Gunung Sewu cave excavation matrices + stone tools** (already excavated; re-sample).
2. **Liyangan volcanic burial matrix** (pre-eruption agricultural surfaces).
3. **Dental calculus** from Gunung Sewu Holocene human burials (Song Keplek/Song Terus skeletons) — untouched, detects individual plant consumption.
