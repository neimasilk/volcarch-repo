# Archeologia e Calcolatori — Submission Rules for P17

**Downloaded:** 2026-03-30
**Source:** https://www.archcalc.cnr.it/pages/policy + https://submission.archcalc.cnr.it

---

## Key Facts

- **Diamond OA** — NO APC, no submission charges
- **Review:** Double-blind peer review
- **License:** CC BY-NC-ND 4.0
- **Deadline:** December 31st (annual)
- **Scopus + WoS indexed**

## Format Requirements

| Item | Requirement |
|------|-------------|
| Word count | ~6,000 words (including references, captions, author info) |
| Languages | English, French, German, Italian, Spanish |
| Font | Times New Roman 12pt, justified, 24pt line spacing |
| Format | RTF or DOCX (NOT LaTeX!) |
| Abstract | English, max 200 words |
| Citations | Harvard system: (Author 1995), (Author et al. 1995) |

## File Submission

Must submit as SEPARATE files:
1. **Main text** — DOCX or RTF (no images embedded)
2. **Bibliography** — separate DOCX or RTF file
3. **Images** — separate ZIP archive (NOT in main text)
4. **Image captions** — separate DOCX or RTF file

## Structure

- Title in CAPITAL LETTERS
- Headings in small caps
- Subheadings in italics
- Paragraphs enumerated hierarchically

## Double-Blind Requirements

- **Remove author names** from manuscript
- **Remove self-citations** that identify authors (or refer to them in 3rd person)
- P17 current issues to fix: self-citations to "Amien" papers, VOLCARCH references
