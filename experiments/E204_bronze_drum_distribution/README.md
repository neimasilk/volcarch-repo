## Hypothesis

If pre-Hindu cultures existed in volcanic Java (as VOLCARCH claims), durable metal artifacts should survive volcanic burial even when organic materials do not. Bronze drums (nekara) are heavy, metal, and diagnostic of Dong Son / Metal Age culture (300 BCE - 200 CE). Their distribution in Java would be DIRECT evidence of pre-Hindu material culture in volcanic zones.

## Method

Literature survey of bronze drum (nekara) distribution across Indonesia, with focus on:
1. How many found in Java vs. other islands?
2. Specifically in volcanic East Java?

5. What accompanying artifacts?

Nearly 40 bronze drums have been found in Java, with the majority discovered in "eastern territories" — the volcanic heartland of East Java. This is the single most direct piece of pre-Hindu material culture evidence in volcanic Java.

### Finding 2: The Tuban Nekara — Heger Type II with Bronze Elephant

The Tuban drum from East Java (now in Museum Mpu Tantular) is classified as Heger Type II, dating to approximately **300 BCE**. It was found:
- **Upturned** (inverted, possibly ritually deposited)
- **Containing a bronze elephant figurine and a bronze axe**
- **Possibly cast locally** in Java using imported tin/copper ingots

**VOLCARCH significance:** This drum was found in Tuban — a coastal regency in East Java with Kelud and Arjuno-Welirang volcanoes in its hinterland. The bronze elephant inside suggests Southeast Asian trade connections (elephants = mainland SE Asia), while the local casting suggests Java had its own bronze metallurgy before Hindu cultural arrival.

### Finding 3: Java as Production Center, Not Just Recipient

The Pejeng-type drums (distinct from Dong Son imports) were "produced extensively in the island of Java and Bali in the first millennium AD." But the presence of Heger Type II drums (300 BCE) in East Java proves that metal-working culture predates any Hindu-Buddhist influence.

Critical distinction:
- **Heger I/II** (imported or early local): 300 BCE - 100 CE = PRE-HINDU
- **Pejeng type** (Java/Bali production): 1st millennium CE = overlaps with Hindu period

The pre-Hindu drums prove that East Java had:
1. Access to bronze metallurgy
2. Participation in Dong Son trade network (extending to Vietnam)
3. Ritual practices (inverted drums = burial/offering contexts)
4. Sufficient social complexity to acquire/produce bronze objects

### Finding 4: WHY Drums Survive When Settlements Don't

**This is the key taphonomic insight:**

| Material | Survives volcanic burial? | Survives tropical weathering? | Found in Java? |
|----------|:-:|:-:|:-:|
| Bronze (nekara) | YES (metal) | YES (corrosion-resistant) | YES (~40) |
| Stone (megaliths) | YES | YES | YES (Gunung Padang etc.) |
| Iron (tools) | PARTIAL (oxidizes) | PARTIAL | RARE |
| Wood (houses) | NO (burns/rots) | NO | NO |
| Bamboo (structures) | NO | NO | NO |
| Palm leaf (texts) | NO | NO | NO |
| Pottery (ceramics) | YES (fragments) | PARTIAL | VERY FEW pre-Hindu |

**Bronze drums survived precisely BECAUSE they are metal.** The ~40 drums are the SURVIVORS of a much larger material culture that included organic architecture, wooden tools, textile, and perishable ritual objects. The drums are the tip of an iceberg whose organic body has been dissolved by volcanism and tropical weathering.

**Quantitative implication:** If we assume bronze drums represent ~1% of total material culture objects (a conservative estimate for any pre-modern society), then ~40 surviving drums imply ~4,000 total material culture items that SHOULD have existed. At E196's population estimate of 1-2 million people at 400 CE, this is EXTREMELY low — confirming massive taphonomic loss.

### Finding 5: Selective Survival Reframes the Argument

VOLCARCH has argued: "Zero pre-400 CE sites in volcanic Java."

This is technically wrong. There IS pre-400 CE evidence in volcanic Java:
- ~30 bronze drums (Eastern Java)
- Dong Son bronze axes
- Megalithic structures (Bondowoso)
- Homo erectus fossils (Sangiran — much older, but proves burial-and-survival CAN happen in deep time)

The CORRECT argument is: **There are zero pre-400 CE SETTLEMENT SITES in volcanic Java.** Individual artifacts (especially metal and stone) survive, but the ORGANIC SETTLEMENT MATRIX (houses, granaries, water systems, roads) does not. The bronze drums prove people were there — the absence of their settlements proves taphonomic erasure.

**This is a much STRONGER argument than "zero evidence."** It's: "we have the indestructible artifacts but none of the perishable settlements."
